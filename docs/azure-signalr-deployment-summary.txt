What works now
--------------
- POST /api/analyze-screenshot validates the incoming screenshot.
- The Function publishes an AiAnalysisCompleted SignalR event.
- POST /api/negotiate issues the short-lived URL and access token used by the SignalR client.
- Azure SignalR owns the persistent connection to browser clients; the Function remains stateless and thin.

Important local-development note
--------------------------------
Local Azurite is not required for the deployed-infrastructure test.
For deployed SignalR testing, use the deployed Function endpoint and a local Angular client.

Next MVP steps

2. End-to-end transport test

   - Verify the Function returns HTTP 202.

3. Deploy Angular
   - Host the static Angular application in Azure.
   - Add the production Angular URL to Function App CORS.
   - Repeat the SignalR transport test with both Function and Angular deployed.

4. Add Foundry

   - Authenticate Function -> Foundry through the existing UAMI.
   - Keep Foundry infrastructure behind an interface.
